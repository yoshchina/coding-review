# 代码审查和反馈记录

这个仓库用于记录所有代码提交的审查意见和反馈。

## 审查流程

1. **代码提交** - 在相关项目仓库中提交代码
2. **创建 Issue** - 在本仓库创建 Issue，记录审查信息
3. **审查反馈** - 详细记录代码质量、安全性、性能等方面的建议
4. **追踪改进** - 跟踪反馈的实施情况

## 审查清单

审查时关注以下方面：

- ✅ **代码质量** - 可读性、命名规范、代码结构
- ✅ **功能完整性** - 是否实现了需求
- ✅ **性能考虑** - 算法效率、资源使用
- ✅ **安全性** - 输入验证、权限控制
- ✅ **可维护性** - 文档、注释、测试覆盖
- ✅ **最佳实践** - 遵循语言和框架规范

## 如何使用

### 创建审查记录
1. 在本仓库创建 Issue
2. 标题格式：`[审查] 项目名称 - 功能描述`
3. 使用审查模板填写详细信息

### 标签管理
- `审查中` - 正在进行审查
- `已完成` - 审查完成
- `需改进` - 发现需要改进的问题
- `已验收` - 改进后已验收
